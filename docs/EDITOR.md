# Aurora editor

Build both binaries with `cargo build --locked --workspace`. Launch `target/debug/aurora-editor` to open Projects. On first launch, choose a default projects folder. The suggestion is `~/Aurora`. **Settings** on the Projects screen can change it later.

| Platform | Preferences file |
| --- | --- |
| Linux | `~/.aurora/config` |
| Windows | `%APPDATA%/Aurora/config` |
| macOS | `~/Library/Application Support/Aurora/config` |

**New Project** asks for a name, parent folder, and starting scene type. Choose **2D** or **3D**; either project can contain both pixel-space and spatial nodes. **Create & Edit** creates a fresh subfolder containing `assets/`, `main.scene`, and TypeScript support. **Import Project** opens an existing project folder or scene. Browse, type a path, or drop a folder or scene onto the Projects screen. Search Recent and double-click an entry to open it. Existing projects with legacy scene and prefab extensions still open under their current filenames. Forget removes it from the list and keeps its files. On Linux, Recent retains its catalog in `$XDG_DATA_HOME/aurora/projects.json`, defaulting to `~/.local/share/aurora/projects.json`.

## Project TypeScript SDK

The editor installs `.aurora/index.d.ts`, its SDK declaration modules, and `.aurora/tsconfig.json`. The root `tsconfig.json` extends Aurora's generated config and resolves `import ... from "aurora"` for type checking, including the `property` decorator. Previous generated SDK paths continue resolving through the current declaration. If the project already has a custom `tsconfig.json`, keep it and add `"extends": "./.aurora/tsconfig.json"` or an equivalent `paths` mapping for `aurora`.

Projects without generated files receive the current SDK on open. If the generated SDK records a different editor version, **Update & Edit** confirms replacement before the project opens. Keep a backup or commit before updating scripts for an SDK change. The editor refreshes generated files in place and preserves the root config and source files. On each open it also refreshes generated contents changed within the same editor version. SDK files and script preview wire bindings are generated inside the editor without invoking Cargo or TypeScript.

Use `target/debug/aurora-editor --project /path/to/project` to open the editor directly. This also accepts individual scene and prefab files. A directory without a scene opens an unsaved Canvas in this direct launch mode. Ctrl+S saves scene changes.

- Select nodes in the hierarchy or click sprites in the Scene view. Double-click a text node in Scene view to edit its first text run in place; press Escape or click outside it to finish. Use Up and Down in the focused tree to move through visible rows, F2 and Enter to rename, and Ctrl+D to duplicate. Drag a node onto another node to reparent it, or onto the root drop target to unparent it. Use the context menu to save a subtree as a prefab. Double-click a prefab asset to edit its isolated tree.
- Click a Built-in Node Library tile to add it under the selected node; with no selection it becomes a child of the scene root when one exists. Drag a tile into the Scene view or Scene Tree to choose its placement.
- Drop PNGs onto the app to import them. Drag a PNG onto a node to attach or replace its sprite, or drop it into the viewport to place a new sprite. In Scene view, drag a selected 2D node to move it and drag a square corner handle to scale it without using Inspector fields. Hold or release Ctrl during a drag to toggle uniform scaling live. Text handles increase or decrease styled font sizes as needed and compensate the node scale to keep glyphs crisp. The viewport also supports right-drag panning, scroll zoom, rulers that adapt to the zoom, and anchor markers. Click a sprite to select its drawn bounds or click empty space to clear selection.
- Create a TypeScript component from the Assets menu. The template imports `aurora` and uses `@ccclass` and `@property`. See the [scripting guide](SCRIPTING.md). Drag its asset onto a node or choose it from Add Component. The inspector uses metadata to accept node and prefab reference drops and persists the resulting values. Fields declared with a component class, such as `@property(Health)`, show a searchable list of the document's components and store the referenced node and component name. Audio clip and sprite frame fields list the scene's registered sound and frame-bank assets.
- In Timeline, create a clip, choose a node and transform channel, and add keys at the cursor. Edit values, key times, and cubic incoming/outgoing slopes in the track rows or drag keys on the curve editor. Choose Step, Linear, or Cubic interpolation. Preview with the transport or scrub the time ruler. Autoplay selects the clip used on entering the scene.
- Play bundles all components attached directly to the open scene for Bun or Node and starts a separate player process. The player renders using offscreen wgpu, with the scene’s aspect ratio and a 960-pixel cap on the longest edge and publishes complete RGBA frames at up to 20 Hz. Game view scales that texture to fit its dock. The console receives child diagnostics. Changes to watched TypeScript and prefab files rebuild the preview. TypeScript changes also refresh Inspector metadata. Failed rebuilds leave the previous running preview available. Pause and Stop control the current child process. F5 starts Play and F8 stops it.
- Move and float the dock tabs. The Panel menu toggles them, and the Layout menu saves or resets the project arrangement. Layout is stored under the document directory in `.aurora/layout.json`.
- Browser and Projects are available in the main menu row. The Node Library's Built-in items wrap into columns to fit the panel width. In FileSystem, drag the divider between the folder tree and asset list to resize the tree. When the dock is narrow, use the ≡ actions menu to create, delete, refresh, or change the file view. Right-click a folder or file to show its containing folder in the system file browser or delete it with confirmation; folder deletion removes its contents.
- Project → Display Settings saves the design resolution and Contain, Cover, or Stretch fit policy in the scene. The Game view forwards key presses and releases, mouse wheel deltas, pointer press, drag and release, and every real multi-touch contact with its own identity. Pointer drags keep the node captured on press, matching the standalone window. Losing window or Game view focus cancels the mouse and all active touches. Space, Up and coordinate-free touch remain available.
- Ctrl+S saves the current scene and Ctrl+O opens the project browser. F2 renames the selected node, Ctrl+D duplicates it, F5 starts Play, and F8 stops Play. Use `--screenshot PATH` to capture the Projects screen. Add `--project PATH` for the editor and `--play` to wait for an embedded game frame.

Engine releases contain the editor/player for supported desktop hosts. Current **Export** output is a locally runnable folder for the editor's host OS: it contains the scene bundle, a matching `aurora-player`, a `run-game` launcher, and `export.json` integrity metadata. It is not a downloadable target template or cross-compilation package; scripted builds currently run on Linux and macOS through the Unix transport. Downloadable target runtimes and hosted builds remain future work. See [the platform build package status](BUILD_PACKAGES.md).

The Node Library includes Empty Node, Sprite, Text, Rich Text, Particles, Tile Map, Atlas Sprite, Nine-Slice, spatial 3D nodes, and project prefabs. Configure 2D visuals in the Inspector; text supports multiple styled runs and project TTF/OTF fonts. The Scene view previews these nodes using the same geometry as Play. Select sibling nodes in the hierarchy and choose **Group** to preserve their poses under a new parent. See [authored 2D visuals and spatial nodes](SCENES.md#text-particles-and-textured-2d-nodes) for supported formats and limits.

Spatial nodes show a wireframe for cubes and imported meshes through an orbitable perspective camera in Scene view. Click a projected shape or node marker to select it; drag it to translate across the projected X/Y plane. Middle-drag in Scene view to orbit the 3D camera, and use **Reset view** to return to the default angle. The Inspector edits position, rotation, scale, material base color, metallic and roughness, cuboid physics, and camera field of view. Imported meshes shade with their base-color texture when the glTF supplied one. The editor does not yet provide 3D script physics.
